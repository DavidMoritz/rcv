About Borda Count

The Borda count is a point-based voting method. Each voter ranks the candidates, and points are awarded based on position:

  • 1st place: {{bordaResults.cap - 1}} points
  • 2nd place: {{bordaResults.cap - 2}} points
  • 3rd place: {{bordaResults.cap - 3}} points
  • ...and so on down to 0. Ranks beyond {{bordaResults.cap}} are unscored.
  • ...and so on. Last place and unranked candidates receive 0 points.

The candidate with the most total points wins. Unlike standard ranked choice voting (RCV), which eliminates candidates round by round, Borda rewards broad support across all voters.

When Borda works well: Contests where voters genuinely like multiple options such as chili cook-offs, movie night, or "best of" polls. Borda surfaces the option with the broadest appeal.

When standard RCV is the better fit: Elections where voters have a clear preference for one candidate over others, such as electing a new board member or vacation destination. Standard RCV ensures the winner has true majority support.

Note: The RCVis graph is not available in Borda mode since Borda does not use rounds.

Switching is disabled because the results are currently public (no future results release date set). To enable switching, edit the ballot and set a results release date in the future.
