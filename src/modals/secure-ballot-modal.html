Secure Ballot

Secure ballots use system-generated codes for verified voting. Each voter receives a unique code that must be entered before they can cast a ballot.

This ensures that only authorized voters can participate and that each code can only be used once.

What changes with a secure ballot?

  • A voting cutoff time is required and set automatically
  • Tie-break is set to Random (official)
  • Voter names are replaced by voter codes

Managing voter codes

After creating the ballot, generate and manage voter codes from the ballot management page in your profile. You can add codes at any time, assign labels, and track which codes have been used.
