Iframe URL on Voting Page

This optional field lets you embed custom content (e.g. an image, custom instructions, company promotional material, etc.) on the voting page, replacing the default "Order by Preference / Drag & Drop" headings. The candidate list and voting buttons remain below.

Sizing the iframe

The iframe is set to 100% width. Prefer a white background for continuity. To control the height, add a small script to your hosted page that sends its height to the parent window: 

<script>
  window.addEventListener('load', function() {
    parent.postMessage(
      { iframeHeight: document.body.scrollHeight },
      '*'
    );
  });
</script>

Ranked Choices will automatically resize the iframe to match.

Requirements

  • The URL must use https://
  • The hosted page must allow embedding (no X-Frame-Options: DENY header)
